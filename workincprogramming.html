My Works in C Programming Course

Here I present all the work I did in the C Programming course last semester.

HackerRank - Work, Certificates and Badges

During the C Programming course, I actively practiced on HackerRank to improve my coding skills. I solved many problems in the C domain, starting from basic ones like "Hello World", "Sum and Difference of Two Numbers", "Playing With Characters", and moving to more challenging topics such as pointers, arrays, functions, and conditionals.

Completing these exercises helped me understand memory management, loops, and how to write efficient code. I earned the C (Basic) certificate after successfully passing the required tests. I also collected several badges for consistency and solving problems in different domains.

HackerRank was very useful because it gave instant feedback on my code. Sometimes I struggled with pointers and string manipulation, but with continuous practice, I improved a lot. I spent many evenings solving problems until I felt confident. This platform not only helped me prepare for exams but also built my problem-solving confidence. I am proud of the progress I made and the certificates I earned through dedication and hard work. I believe these skills will be valuable in my future programming journey.

SoloLearn - Work and Certificates

In addition to classroom learning and HackerRank, I used SoloLearn to study C programming. The platform offers interactive lessons that are easy to follow. I completed the full C course, covering topics from basic syntax, data types, operators, control structures, functions, arrays, pointers, and memory management.

What I liked most about SoloLearn is that I could learn anywhere using my phone. I would solve small challenges during free time. The code coach feature helped me practice writing clean code. After finishing all modules and quizzes, I received the C Programming certificate. I also earned many XP points and badges for completing daily challenges.

SoloLearn made learning fun and engaging. It helped me revise concepts I learned in class and discover new ways of solving problems. The community section allowed me to see other students' solutions, which broadened my thinking. Combining SoloLearn with regular class practice gave me a very solid foundation in C programming. I highly recommend this platform to any beginner who wants to learn programming in an interactive way.

Reflection and Conclusion

Looking back at last semester, the C Programming course was challenging but extremely rewarding. At the beginning, I found concepts like pointers and memory allocation difficult to understand. However, through consistent practice on HackerRank and SoloLearn, I gradually improved. I learned the importance of logical thinking and attention to detail in programming.

This course has prepared me well for future studies in computer science. I now feel more confident when approaching coding problems. I am grateful to my instructor and the online platforms that supported my learning journey.
